# canvas
A simple graphics lib written in rust which renders pixel by pixel in the memory
``
Quick Start
$ cargo run --example shapes
``
- the above command would generate an image in ppm format rendered in the memory by the library
- there are more example to explore just change the shapes by any examples present in the examples dir.
